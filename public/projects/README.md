# Project screenshots

Add approved, genuine screenshots of the actual products in this folder.

Recommended filenames:
- reachmark.webp
- voicebridge.webp
- primevest.webp
- leadflow.webp
- tribe-culture.webp
- web3-systems.webp

Use landscape captures around 1600 × 900 (16:9), optimized as WebP or AVIF.
Do not use generated mockups as evidence of a shipped product. Once a screenshot is added, set the matching `image` field in `data/projects.ts` to `/projects/filename.webp`.

Keep customer data, private dashboards, API keys, account details and unreleased information out of screenshots.
